# Catalog prețuri cablare structurată

Pagină statică (GitHub Pages) pentru consultarea rapidă a prețurilor materialelor.

- `data/produse.json`: catalogul (denumirile exact ca în deviz).
- `data/preturi.json`: sursele și prețurile (se completează automat și/sau manual).
- Editarea (adaugă, arhivează, surse manuale, respinge sursă) se activează din interfață și se salvează deocamdată în browserul folosit.
